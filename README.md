# HomeBase

Book short stays in real homes across Nigeria. Landlords list their homes; guest search, request dates, and pay once the landlord approves.

## User stories

- As a guest, i want to search homes by city and dates, so that i only see places i can actually book.
- As a landlord, i want to approve or decline each request, so that i decide who stays in my home
- As a guest, i want to be able to see the total price of house before asking, so that i can know if it fits in my budget
- As a guest, paying after approval from the landlord should reflect has paid in my dashboard
- Ad a guest, I should get a refund after i canceled my booking
- As a landlord, I want to be able to add photos to my properties, so that anyone booking can know what it looks like before booking.
- As a user, I want to be able to reset my password safely whenever i forget it.
- As a guest, I want to be able to review a stay afterwards, so that others can know if it's a place to stay or avoid.
